# HDFans 规则摘要（公开可读）

> 2026-09-28 抓取


## 规则

- 请不要做管理员明文禁止的事情。
- Extreme User 及以上等级用户会永远保留；
- Veteran User 及以上等级用户封存账号（在 控制面板 ）后不会被删除帐号；
- 封存账号的用户连续180天不登录将被删除帐号；
- 未封存账号的用户连续90天不登录将被删除帐号；
- 没有流量的用户（即上传/下载数据都为0）连续15天不登录将被删除帐号。
- 一切作弊的帐号会被封，请勿心存侥幸。
- 注册多个HDFans账号的用户将被禁止。
- 第一次在论坛或服务器中的捣乱行为会受到警告，第二次您将永远无缘HDFans 。
- 论坛设有专门的求药区，目前要求PU级别方可进入，禁止在群聊区求邀，违反此规定将会受到警告，严重的将禁用账号。
- 下载规则 - 违规将会失去下载权限！
- 过低的分享率会导致严重的后果，包括禁止帐号。
- 上传规则 - 谨记: 违规的种子将不经提醒而直接删除
- 上传者必须对上传的文件拥有合法的传播权。
- 上传者必须保证上传速度与做种时间。
- 如果在其他人完成前撤种或做种时间不足24小时，或者故意低速上传，上传者将会被警告甚至取消上传权限。
- 如果你有一些违规但却有价值的资源，请将详细情况 告知管理组 ，我们可能破例允许其发布。
- 其他用户必须先在 候选区 提交候选。
- PC游戏（必须为原版光盘镜像）；
- 但是，总会保留一个当前最佳画质的来源经重编码而成的DVD5大小（即4.
- 每个无损音轨资源原则上只保留一个版本，其余不同格式的版本将被视为重复。
- 新版本发布后，旧的、重复的版本将被保留，直至断种。
- 打包发布的视频资源必须来源于相同类型的媒介（如蓝光原碟），有相同的分辨率水平（如720p），编码格式一致（如x264），但预告片例外。
- 对于电影合集，发布组也必须统一。
- 打包发布的音频资源必须编码格式一致（如全部为分轨FLAC）。
- 管理组保留资源打包相关问题的解释权和处理权。
- 上述几种文件必须统一打包或统一不打包。
- 电影和电视剧必须包含外部信息链接（如IMDb连接）地址（如果存在的话）。
- 必须包含海报、横幅或BD/HDDVD/DVD封面（如果存在的话）；
- 必须包含专辑封面和曲目列表（如果存在的话）；
- 必须包含海报或BD/HDDVD/DVD封面（如果存在的话）；
- 论坛总则 - 请遵循以下的守则，违规会受到警告！
- 禁止攻击、挑动他人的言辞。
- 禁止恶意灌水或发布垃圾信息。
- 不要为了获取魔力值而大肆灌水。
- 禁止在标题或正文使用脏话。
- 不要讨论禁忌、政治敏感或当地法律禁止的话题。
- 禁止任何基于种族、国家、民族、肤色、宗教、性别、年龄、性取向、身体或精神障碍的歧视性言辞。
- 违规将导致账号永久性禁用。
- 禁止挖坟（所有挖坟帖都要被删掉）。
- 任何用户都可在趣味盒中投放笑话、趣图、搞笑视频、Flash等有趣的内容，除了色情、禁忌、政治敏感和当地法律禁止的内容。
- 票数超过25，其中认为“有趣”比例超过50%，发布者得到5个魔力值。
- 票数超过50，其中认为“有趣”比例超过50%，发布者得到另外的5个魔力值。
- 票数超过100，其中认为“有趣”比例超过50%，发布者得到另外的5个魔力值。
- 票数超过200，其中认为“有趣”比例超过50%，发布者得到另外的5个魔力值。
- 票数超过25，其中认为“有趣”比例超过75%，发布者得到10个魔力值。
- 票数超过50，其中认为“有趣”比例超过75%，发布者得到另外的10个魔力值。
- 票数超过100，其中认为“有趣”比例超过75%，发布者得到另外的10个魔力值。
- 票数超过200，其中认为“有趣”比例超过75%，发布者得到另外的10个魔力值。
- 对于违规行为不要怕说“不”！
- 不要太绝情，给违规者一个改过的机会。
- 字幕区规则 - 违规字幕将被删除
- 所有上传的字幕必须符合规则（即合格的）。
- 管理组保留裁定和处理不合格字幕的权力。
- 对每一例不合格字幕的举报，确认后将奖励举报者50点魔力值（三天内发放）。
- 被确定为不合格的字幕将被删除，而在每一例中，相应的字幕上传者将被扣除100点魔力值。
- 对为赚取积分等目的恶意上传不合格字幕的用户，或是恶意举报的用户，将视情节轻重扣除额外的魔力值甚至给予警告。
- 认领功能主要是考虑长期保种的情况，因此需要做种时间较长，各位会员可根据实际情况认领。
- • 种子发布0天后可以认领。
- • 一个种子最多可以被100个用户认领。
- • 一个用户最多可以认领100个种子。
- • 种子不达标时将被删除并扣除用户 600 魔力(非认领首月)。
- • 用户主动放弃认领扣除用户 400 魔力。
- • 计算达标种子魔力奖励是正常魔力值的 3 倍。
- • 达标标准：每月做种时间大于等于180 小时, 或上传量大于等于其体积3 倍。
- 本站单种上传速度最高为200Mbps，约25MB/s，如有超过此速度的教育网、家宽用户需要自行限速，暂时不支持教育网、家宽作为盒子进行登记。
- 盒子做种的，72小时内只享受种子体积*3的上传量。
- 单种超过100MB/S的，第一次警告，二次禁用账号。
- 使用不被本站认可的盒子进行登记的，第一次警告，第二次扣除500G上传（若现有上传量未达500G，则直接清零），第三次直接封号。
