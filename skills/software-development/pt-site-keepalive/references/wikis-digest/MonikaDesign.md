- 2. 做种要求 2.1 概述 2.1.1 MonikaDesign 是一个分享社区，因此，下载内容后理应做种上传以回馈其他用户。
- 2.1.2 必须保证符合最低分享率要求时，才可以继续使用下载权利。
- 2.1.3 在停止做种前请确认是否还有其他做种者。
- 2.2 做种时间 H&R系统目前处于关闭状态，我希望永远不会开启它 2.2.1 所有种子都需要至少做种2天（48 小时）的播种时间，无论该种子的分享率如何。
- 2.2.2 在完整下载该种子所有文件前不计算做种时间。
- 2.2.3 当下载的文件小于文件总体积的10％时，不计算H&R。
- 2.2.4 对于Free种子，H&R规则仍然适用。
- 2.2.5 如果您尚未达到最低做种时间（48 小时），并且停止做种的时间超过24小时（1 天），您将收到一条自动预警信息，如果您在接下来的48小时内仍未开始做种，则会受到一次H&R警告。
- 2.2.6 如果您已停止做种超过72小时（3 天）且未完成所需的最低做种时间（2 天），您将受到一次H&R警告。
- 2.3 H&R警告 2.3.1 一次H&R警告仅持续生效14 天，但H&R警告的记录将永久保留。
- 2.3.2 14天后H&R警告自动过期。
- 2.3.3 H&R警告记录永久保留。
- 2.3.4 如果你当前有1个生效的H&R警告，什么也不会发生。
- 2.3.5 如果你当前有2个生效的H&R警告，系统将自动禁用下载和悬赏请求功能。
- 2.3.6 如果你当前有3个生效的H&R警告，系统将自动封禁账号。
- 2.4 关于盒子 2.4.1 本站目前对盒子无任何限制。
- 3.2 当且仅当种子长时间无人做种，或孤种无论如何都无法连接上做种者时再使用此功能。
- 3.3 滥用功能可能导致账号受到警告。
- 4. 悬赏请求 4.1 在提出请求之前，请仔细检查网站中是否存在包含你所需要内容的种子。
- 4.2 请求的内容不得凌驾于发布规则之上。
- 如果请求内容不符合MonikaDesign的规则，那么请求会被删除，您将失去积分。
- 4.3 一个请求标题下不得包含多个内容。
- 在请求非单集动画/剧集时，必须请求完整的一季，除非目前正在连载，在这种情况下，可以请求单集。
- 4.6 得到应求发布是一种幸运，因此，您需要下载应求资源并至少做种2周。
- 4.7 如果您的请求有人应答，则必须在14天内确认或拒绝。
- 4.9 当您应征请求时，您有 7 天的时间来发布种子和完成应求。
- 5. 邀请事项 5.1 禁止交易、出售、互换邀请 5.2 禁止在专门从事邀请交易的网站上发放邀请。
- 5.3 不要邀请自己，一经发现立即封禁。
- 5.4 您应对您邀请的用户负全部责任。
- 如果被邀请者严重违反规则，例如账号交易，出售资源，分享率作弊，滥用漏洞等。
- 视情况，您也可能受到警告甚至封禁。
- 5.5 邀请你所信任的人。
- 5.6 邀请权是一项特权，您的邀请权随时可能由管理组撤销。
- 6. 社区礼仪 6.1 总体要求 6.1.1 禁止骂人、对线、阴阳怪气等不礼貌行为。
- 6.1.2 禁止私信轰炸、骚扰他人。
- 6.1.3 禁止在网站上进行任何交易。
- 6.1.4 务必不要将.torrent文件分享给其他人，这可能会导致您的帐号被封禁。
- 6.1.5 禁止发布宣扬种族主义、性别歧视、包含政治意味的言论等。
- 6.1.6 禁止将我们的内部组资源发布到公网BT、论坛、网盘等地，除非原发布者准许。
- 6.1.7 尊重发布者的合理诉求，包括但不限于禁止/限制转载、REMUX、DIY。
- 6.1.8 禁止出售从 MonikaDesign 获取的资源。
- 从本站下载资源并转售将导致您的帐户被封禁。
- 6.2 论坛，种子评论，悬赏请求 6.2.1 请勿滥用评论，如恶意刷屏等。
- 例如，当他们在种子中说“请勿转载”或“请勿在x天内转载”。
- 同样，当您在此处发布您从其他网站获得的资源时，我们希望您遵守原始发布者的意愿，如果您转载了其他网站的独占内容，您发布的种子将被删除，并且可能因此而受到警告甚至封禁。
