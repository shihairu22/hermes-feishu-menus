# SJTU葡萄 规则摘要（公开可读）

> 2026-09-28 抓取


## 规则

- 请不要做管理员明文禁止的事情。
- 不要做挑战管理组的行为，违反直接删除帐号。
- Veteran User 及以上等级用户会永远保留；
- Elite User 及以上等级用户封存账号（在 控制面板 ）后不会被删除帐号；
- 封存账号的用户连续240天不登录将被删除帐号；
- 未封存账号的用户连续120天不登录将被删除帐号；
- 没有流量的用户（即上传/下载数据都为0）连续30天不登录将被删除帐号。
- 一切作弊的帐号会被封，请勿心存侥幸。
- 注册多个葡萄账号的用户，所有账号将被禁止。
- 第一次在论坛或服务器中的捣乱行为会受到警告，第二次您将永远无缘葡萄。
- 禁止任何形式的帐号交易行为！
- 所有涉及商业行为的相关ID和被邀请人,将被永久封禁ID及IP段！
- 下载规则 - 违规将会失去下载权限！
- 过低的分享率会导致严重的后果，包括禁止帐号。
- 上传规则 - 谨记: 违规的种子将不经提醒而直接删除
- 上传者必须对上传的文件拥有合法的传播权。
- 发布者必须在做种累计时间达到24小时且有至少3个做种者后方可撤种，若72小时后无人下载可撤种。
- 违规的种子将不经提醒而直接删除。
- 如果你有一些违规但却有价值的资源，请将详细情况 告知管理组 ，我们可能破例允许其发布。
- Dupe的版本（但已发的Dupe版本会被保留）；
- HR-HDTV，rmvb等清晰度类似介于高清与标清之间，或低于标清的视频文件。
- 其他资源在rmvb或者HR-HDTV已是最优质量时，经过管理员许可，可以上传。
- 断种的定义为超过30天无人做种，允许发布构成dupe的版本
- 必须包含海报、横幅或BD/HDDVD/DVD封面（如果存在的话）；
- 必须包含海报或BD/HDDVD/DVD封面（如果存在的话）。
- 必须包含CD封面（如果存在的话）；
- 电影和电视剧必须包含外部信息链接（ imdb ）地址（如果存在的话）， 豆瓣 地址可选择填写。
- 论坛总则 - 请遵循以下的守则，违规会受到警告！
- 禁止攻击、挑动他人的言辞。
- 禁止恶意灌水或发布垃圾信息。
- 不要为了获取魔力值而大肆灌水。
- 禁止在标题或正文使用脏话。
- 不要讨论禁忌、政治敏感或当地法律禁止的话题。
- 禁止任何基于种族、国家、民族、肤色、宗教、性别、年龄、性取向、身体或精神障碍的歧视性言辞。
- 违规将导致账号永久性禁用。
- 禁止挖坟（所有挖坟帖都要被删掉）。
- 禁止发表纯表情、SF、BD或者类似的评论，如果违反该规则，第一次会被口头警告，第二次会被警告，第三次你将无缘本站。
- 如果用户多次发表该类评论的，经提醒后仍不悔改的，则会被视为故意捣乱而被警告！
- 若违反该条规则，发表不尊重上传者的评论，第一次将会直接被警告，第二次则会被永久封禁！
- 任何用户都可在趣味盒中投放笑话、趣图、搞笑视频、Flash等有趣的内容，除了色情、禁忌、政治敏感和当地法律禁止的内容。
- 票数超过25，其中认为“有趣”比例超过50%，发布者得到5个魔力值。
- 票数超过50，其中认为“有趣”比例超过50%，发布者得到另外的5个魔力值。
- 票数超过100，其中认为“有趣”比例超过50%，发布者得到另外的5个魔力值。
- 票数超过200，其中认为“有趣”比例超过50%，发布者得到另外的5个魔力值。
- 票数超过25，其中认为“有趣”比例超过75%，发布者得到10个魔力值。
- 票数超过50，其中认为“有趣”比例超过75%，发布者得到另外的10个魔力值。
- 票数超过100，其中认为“有趣”比例超过75%，发布者得到另外的10个魔力值。
- 票数超过200，其中认为“有趣”比例超过75%，发布者得到另外的10个魔力值。
- 简介除了对内容的介绍，还必须包括以下内容：
- 海报图片（必须），影片截图（推荐）
- imdb链接必须填写到指定位置（若有）。
- 字幕规则 - 不遵守这些将导致被警告！
- 上传的字幕标题前缀必须与种子标题一致。
- 上传字幕前必须先验证时间轴的准确性，以及内容的翻译质量，切勿上传翻译软件翻译的字幕。
- 处罚 ：对于违反以上规则上传字幕文件的，将酌情给予口头警告、双倍扣除上传字幕所获得的魔力值、乃至警告的处罚。
- 奖励 ：凡发现违反规则的字幕的，请到投诉区字幕违规举报专帖中举报，我们确认后将给予举报者一定的奖励。
