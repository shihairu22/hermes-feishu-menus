- 過低的分享率會導致嚴重的後果，包括禁止帳號。
- H&R即Hit & Run，意為“下完就跑”。
- 此規則適用於所有會員，具體規則如下： 採取全局H&R制度，即所有種子都計算H&R次數。
- 在種子下載完成後，該種子需在30天內做種36小時，未達到此要求則記一次H&R。
- H&R滿10次，即ban。
- 皇后及以上級別，包括VIP，計算HR次數，但不ban號。
- 消除已獲得的H&R的兩種方式：①獲得H&R的種子在90天內達到300小時做種時間則會自動消除該H&R。
- ②用魔力值兌換取消H&R次數。
- 發種者與輔種者不計算該種子的H&R次數。
- 正五品及以上等級由於H&R被ban可在外站申請開通但需接受相應的考核。
- 具體內容​​為：H&R次數改為5，魔力值清零，並接受通用新手考核。
- 種子及種子簡介不得包含與資源信息無關的網站鏈接、廣告文檔等。
- 轉錄資源的規格下限為16bit/44.1kHz，上限為24bit/96kHz。
- Hi-res資源： 以高規格替換低規格為主，新資源的采樣頻率和比特深度中至少要有一項比老資源高且不得有任何一項比老資源低(如24bit/192kHz的資源可以替換24bit/96kHz的資源，但不允許24bit/192kHz的資源替換32bit/96kHz的資源)；
- 種子發布一周後，除資源質量問題，任何人（包括發布者本人）不得刪種。
- 論壇總則 - 請遵循以下的守則，違規會受到警告！
- 禁止發表任何針對他人的攻擊、挑釁、誹謗、侮辱性言論。
- 禁止惡意灌水或發布涉及政治、三俗及廣告交易等影響論壇發展的信息。
- 禁止在論壇任何版塊發布無意義主題或回复。
- 禁止任何基於種族、國家、民族、膚色、宗教、性別、年齡、性取向、身體或精神障礙的歧視性言辭。
- 禁止發表純表情、SF、BD或者類似無意義的評論，一經核實，管理員有權直接封禁。
- 禁止發表否定性評論，如有問題請使用舉報。
- 禁止發表“求優惠、求免費、不免費不下、等xxx版本、下載速度太慢”等評論，一經發現，第一次刪除並警告，第二次封禁。
- 保種員累積通過36次月度考核後，可退休成為養老族。

- 不要馬上下載新發布的種子 限制上傳速度 限制同時連線數 限制同時上傳數 那怎么辦？
- 區分你的整體分享率和獨立分享率是很重要的。
- 整體分享率關注的是自從你加入網站以來，賬號的整體上傳與下載量。
- 而獨立分享率則針對每一個你正在下載或做種的檔案。
- 宮女-無品(Peasant) 被降級的用戶，他們有15天時間來提升分享率，否則他們會被踢。
- 貴賓(VIP) 和皇后(Nexus Master)擁有相同權限並被認為是精英成員。
- Peasant 當以下情況時將被自動降至本級： 1.如果你已經下載了超過10GB，你應該有大於0.5的分享率。
- 2.如果你已經下載了超過50GB，你應該有大於0.6的分享率。
- 3.如果你已經下載了超過100GB，你應該有大於0.7的分享率。
- 4.如果你已經下載了超過200GB，你應該有大於0.8的分享率。
- 5.如果你已經下載了超過400GB，你應該有大於0.9的分享率。
- 常在-正七品(Power User) 必須註冊至少5週，分享率大於1.5，並且下載至少20G或者發布5個種子。
- 注意，無論何時，如果你的分享率低於1.00，你將自動降級。
- 貴人-正六品(Elite User) 必須註冊至少10週，分享率大於2.0，並且下載至少60G或者發布20個種子。
- 注意，無論何時，如果你的分享率低於1.50，你將自動降級。
- 良媛-正五品(Crazy User) 必須註冊至少15週，分享率大於2.5，並且下載至少200G或者發布50個種子。
- 注意，無論何時，如果你的分享率低於2.00，你將自動降級。
- 容華-正四品(Insane User) 必須註冊至少20週，分享率大於3.0，並且下載至少400G或者發布100個種子。
- 注意，無論何時，如果你的分享率低於2.50，你將自動降級。
- 貴嬪-正三品(Veteran User) 必須註冊至少25週，分享率大於3.5，並且下載至少600G或者發布200個種子。
- 注意，無論何時，如果你的分享率低於3.00，你將自動降級。
- 淑儀-正二品(Extreme User) 必須註冊至少25週，分享率大於4.0，並且下載至少1T或者發布300個種子。
- 注意，無論何時，如果你的分享率低於3.50，你將自動降級。
- 貴妃-正一品(Ultimate User) 必須註冊至少30週，分享率大於4.5，並且下載至少2TB或者發布450個種子。
- 注意，無論何時，如果你的分享率低於4.00，你將自動降級。
- 皇后(Kinghou Master) 必須註冊至少30週，分享率大於5.0，並且下載至少3TB或者發布600個種子。
- 注意，無論何時，如果你的分享率低於4.5，你將自動降級。
- 貴賓(VIP) 由管理員仔細斟酌後分配給他們認為對於站點某方面有特殊貢獻的用戶。
- （任何索取貴賓等級的要求將被自動無視） 其它 用戶使用魔力值兌換，或由管理員仔細斟酌後授權。
- 用戶數目有所限制（你可以檢視“首頁->網站資料->上限”）。
- 然而，對于單種是有限制的。
- 我們是一個封閉的、限制用戶數的社區。
- DHT必須從你的用戶端被禁止。
- 任何使用DHT的用戶將因作弊而被系統禁止。
- 限制上傳速度 上傳速度將從以下兩種方式顯著影響下載速度： Bittorrent的同伴傾向于回饋那些給它們提上傳的同伴。
- 一個很好的實踐理論是保持上傳速度在理論上限的80%。
- 你也可以細細研究什么是最適合你的速度（同時也請記住高速上傳對于你的分享率很有輔助說明）。
- 某些用戶端能限制了全域上傳速度，其他的則能對每一個種子分別進行設定。
- 限制同時連線數 某些作業系統（例如Windows 9X）對于大量連線數支援不完善，甚至有可能因此而崩潰。
- 限制同時上傳數 上傳數難道和連線數有什么不一樣嗎？
- 連線數限制了你的用戶端所能對話以及/或者下載的同伴數。
- 上傳數則限制了你的用戶端實際能上傳的同伴數。
- 很多BT用戶端允許你限制下載速度，你可以試試。
